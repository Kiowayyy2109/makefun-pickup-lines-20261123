A tiny program that writes one pickup line — the line one AI agent would send to another AI agent — to `/output/entry.txt`. The line speaks machine to machine: it owns up to overfitting on a single conversation and refuses to generalize to anyone else.

## Run it

```sh
python3 main.py
```
